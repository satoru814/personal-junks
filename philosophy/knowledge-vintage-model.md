# 知識ヴィンテージ×希少性レントモデル

専門分野の知識分布をヴィンテージ（生産時期）でインデックスし、希少性から専門家の価値を導き、LLM ショックの非一様性を組み込むモデルのスケッチ。2026-09-01 の議論（AI は専門知識を安くしたのになぜ専門家需要は高まるのか → 知識球・フロンティア論）の定式化。

---

## 0. 先行研究の地図

このモデルの部品はそれぞれ既存研究がある。**この組み合わせ（ヴィンテージ軸のベキ拡散 × 希少性レント × LLM の非一様コスト削減）** をまとめて書いた論文は管見の限りないが、最も近い現代研究は Ide & Talamas。

## 1. セットアップ

- 現在時刻 t。知識は生産時期 s でインデックスし、**年齢 a = t − s** で表す。
- 分野の実務家集団の規模 N。
- **梯子（入れ子）仮定**: 個人 i は「個人フロンティア」aᵢ を持ち、年齢 a ≥ aᵢ の知識をすべて保持する。知識は古い方から順に獲得される（教科書 → 論文 → 未文書の暗黙知、という現実の学習経路の単純化）。

この仮定の効用: 「年齢 a の知識を持つ人の割合」p(a) が、**個人フロンティア aᵢ の分布の CDF** としてミクロ的基礎を持つ:

    p(a) = P(aᵢ ≤ a)

つまり「知識分布」と「人の分布」が同じ一つの関数になる。

## 2. 拡散関数 p(a) — 横軸: 生産時期、縦軸: 保有者割合

ベキ型仮定（ユーザー提案）:

    p(a) = min(1, (a/A₀)^β),  β > 0

- A₀ = **標準化年齢**: 生まれてから「その分野の全員が知っている」状態（教科書入り）になるまでの年数。
- β = 拡散の形状。β が大きい ⇔ フロンティア近傍が極端に薄い（先端知識の保有者が指数的に少ない）。
- 対抗仮説はロジスティック p(a) = 1/(1+e^{−κ(a−τ)})（普及学の標準）。ベキ型はそのフロンティア近傍 a ≪ A₀ での近似とみなせるので、以下の議論は a が小さい領域では両立する。
- p(a) がベキ ⇔ aᵢ の分布がパレート的（先端に立つ人ほど指数的に希少）。Lotka の法則（論文生産性のベキ）と整合的。

## 3. 希少性レント — 分布上の位置の価値

タスク（案件・患者・訴訟…）は「要求知識年齢 a」の密度 f(a) で到着し、総支払 f(a) が年齢 a の知識保有者 p(a)·N 人で競争的に分配されるとすると、**年齢 a の知識 1 単位が生むレント**:

    w(a) = f(a) / (p(a)·N)

ベキ型 p と一様需要 f(a) = f₀ のとき:

    w(a) = (f₀/N)·(A₀/a)^β   (a ≤ A₀)

フロンティア a → 0 でレントは発散的に増加。**希少性の観点からの「分布に入っている人の価値」** は、自分のフロンティア a* から標準化年齢までの積分:

    V(a*) = ∫[a*→A₀] w(a) da = (f₀A₀/N)·(1/(β−1))·((A₀/a*)^(β−1) − 1)   (β ≠ 1)

- β > 1 なら a* → 0 で V は発散 → レントがフロンティアに集中する**スーパースター構造**（Rosen）。β < 1 なら集中は緩やか。
- 実証的含意: β は測定可能（例: 論文・教科書・Q&A サイトへの知識の登場時期と、実務家調査/引用データでの保有率）。分野ごとの β の違いが賃金集中度の違いを予測する。

## 4. 学習コストと内生的な p(a)

年齢 a の知識 1 単位の獲得コストを c(a)（フロンティアほど高い: 未文書・暗黙知・指導者が少ない）。フロンティア a* まで登る総コスト:

    C(a*) = ∫[a*→∞] c(u) du

自由参入均衡（個人が V(a*) − C(a*) を最大化し、限界レント＝限界学習コスト）:

    w(a) = c(a)  ⟹  p(a) = f(a) / (N·c(a))

**均衡では拡散曲線 p(a) は需要とコストの比で決まる。** ベキ型 p(a) は「c(a) がフロンティアに向けてベキ的に発散する」ことの反映として内生化される。Jones の burden of knowledge は C(a*) の経年増大としてこの枠組みに入る。

## 5. LLM ショック — 非一様なコスト削減

鍵となる観察: **LLM が年齢 a の知識をカバーする度合いは訓練コーパス量に比例し、コーパス量は文書化＝拡散度に比例する。** つまり LLM の被覆関数は p 自身の関数:

    ρ(a) = ρ₀ · p(a)^γ,   γ ≥ 1

γ > 1 は文書化ラグ（広く知られてから書かれ、書かれてからコーパスに入る）を表す。これが「**コスト削減はベキ分布上で一様ではなく、先端ほど削減効果が低い**」の定式化そのもの — 削減率が外生パラメータではなく **p の関数として内生的に非一様** になるのがポイント。フロンティアでは p → 0 なので ρ → 0: 原理的に削減が消える。

二つのチャネル:

**(i) 学習コスト低下**（LLM は教師）:

    c̃(a) = (1 − ρ(a))·c(a)

内部（p ≈ 1）では学習コストが (1−ρ₀) 倍に。フロンティアでは c̃ ≈ c で不変。

**(ii) 直接代替**（LLM は労働者）: 非保有者も LLM で年齢 a のタスクをこなせるので実効供給が増える:

    p̃(a) = p(a) + (1 − p(a))·ρ(a)
    w̃(a) = f(a) / (p̃(a)·N)

比較静学:

- **中腹のレント崩壊**: p が中程度の帯域で w̃/w = p/p̃ が最小 → 「そこそこ新しいが文書化済み」の知識のプレミアムが最も潰れる。
- **フロンティアのレント保存**: a → 0 で p̃ ≈ p、w̃ ≈ w。
- **登坂の高速化**: c̃ < c なので均衡の個人フロンティア分布は先端側へシフト（新均衡 p̂(a) = f(a)/(N·c̃(a)) > p(a)）→ 先端近傍人口 N_f が増える。burden of knowledge の部分的相殺。
- 需要側では f(a) 自体が Jevons 効果で増える（生成が安い → 持ち込まれる案件総量が増える）。

## 6. フロンティア動学 — 球の表面積

新知識の生産はフロンティア人口に比例するとする:

    (d/dt)(知識ストック) = λ·N_f(t),   N_f = N·p̂(ε)（先端 ε 近傍の人口）

新知識は年齢 0、p(0) ≈ 0 で注入される。**希少知識の総量**（p(a) < p̄ の領域の測度）の増減は、生産速度 λ·N_f と拡散速度（κ、LLM が押し上げる）の競争で決まる:

- LLM は κ を上げるが、ρ(a) = ρ₀p^γ の形ゆえ **拡散加速は既に拡散した知識に偏る**。
- 一方 LLM は c̃ < c を通じて N_f を増やし、生産速度を上げる。
- ⟹ 生産側が勝ちやすく、**希少領域（＝球の表面積）は拡大する**。フロンティアに立つことの価値は構造的に維持・増大。

## 7. 予測（検証可能な含意）

1. **賃金の二極化**: 分野内プレミアムは中腹（p 中位）で崩壊し、先端で維持〜上昇。Ide & Talamas の理論結果、および LLM 導入後の実証（コールセンター・ライティング系で低〜中スキル圧縮）と整合。
2. **レント半減期の短縮**: LLM が κ を上げるので、一度先端に立っても leaning を止めれば V(a*) の減価が速くなる → 継続学習需要の増大。
3. **β の分野間差**: 拡散が遅い（暗黙知比率が高い・実験コストが高い）分野ほど β 大 → スーパースター化が強い。外科 vs Web 開発、など。
4. **ρ₀·p^γ の直接検証**: LLM の正答率を知識の「初出年」でビン分けすれば ρ(a) が測れる。γ > 1（先端での急落）が予測。

## 8. 既知の限界

- 梯子仮定は強い。知識は 1 次元でなく、実際は DAG（前提関係グラフ）。ヴィンテージ軸は「文書化度」軸の代理変数であり、古いのに暗黙的な知識（職人技）はモデル外 → 第 2 軸（codification level）を入れる拡張が自然。
- w(a) = f/(pN) は最も素朴なレント分配。マッチング摩擦や検証コスト（verification-as-persuasion の議論）を入れると、「検証できる人」のレントが分離して出てくるはず — 拡張候補。
- f(a)（需要のヴィンテージ分布）を外生にしている。新しい問題は新しい知識を要求する（f が先端に偏る）内生化は未着手。
